# goToWork

`goToWork` 是一个基于 Python 和 Tkinter 的 Windows 桌面悬浮工具，用于显示下班倒计时、工作进度和收入估算。

## 功能

- 显示距离下班的倒计时和当日工作进度。
- 根据配置的月薪、工作日和工时估算今日收入、时薪及日薪。
- 显示本月累计收入估算和距离发薪日的天数。
- 支持悬浮窗拖动、窗口置顶和位置锁定。
- 提供系统托盘菜单，可显示或隐藏窗口、打开设置、最小化或退出程序。
- 配置保存在程序同目录的 `config.json` 中。

## 运行

安装 Python 3 后，在项目目录运行：

```powershell
python main_tk.py
```

首次启动时填写薪资和工作时间信息。保存后程序开始显示悬浮窗；后续设置可从窗口菜单或托盘菜单打开。

## 操作说明

- 未锁定时，按住窗口任意区域并拖动即可移动悬浮窗。
- 在窗口右上角点击 `×` 打开窗口菜单，可切换置顶或锁定状态，也可打开设置、最小化或退出。
- 右键单击系统托盘图标可执行对应的窗口和程序操作；左键单击托盘图标可切换窗口显示状态。

## 打包

项目包含 PyInstaller spec 配置。安装 PyInstaller 后，在项目目录执行：

```powershell
pyinstaller 上班鼓励器.spec
```

打包生成的程序名称由 spec 配置决定，当前为 `goToWork.exe`。
