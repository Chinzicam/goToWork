# goToWork

`goToWork` 是一个基于 Python、Tkinter 的 Windows 桌面悬浮工具，用于查看下班倒计时、有效工作进度和收入估算。

## 功能

- 显示距离下班的实际剩余时间。
- 依据上班时间、下班时间和午休时段计算有效工作时长；午休不计入工作进度和当日收入。
- 根据月薪、每月工作天数和每日有效工时估算时薪、今日收入与满勤日薪。
- 显示本月累计收入估算和距离发薪日的天数。
- 支持悬浮窗拖动、窗口置顶和锁定位置。
- 提供系统托盘，可切换窗口显示状态、打开设置、最小化或退出。
- 配置保存在程序同目录的 `config.json` 中。

## 设置

设置页包含以下项目：

- 月薪（元）
- 月工作天数
- 上班时间（点）
- 午休开始时间（点）
- 午休结束时间（点）
- 下班时间（点）
- 每月发薪日（号）

时间按 24 小时制输入，可使用小数表示分钟，例如 `9.5` 表示 9:30。上班、午休开始、午休结束、下班时间必须依次递增。每日有效工时由上下班时间减去午休时长自动计算，无需单独填写。

## 计算口径

- 下班倒计时按当前时刻到下班时刻计算，因此午休期间倒计时仍会继续。
- 工作进度与今日收入只累计上班至午休开始、以及午休结束至下班的时间；午休期间暂停累计。
- 时薪估算为月薪除以“每月工作天数 × 每日有效工时”。
- 今日满勤日薪估算为月薪除以每月工作天数。
- 本月累计收入是按已过自然日乘以估算日薪的简化估算值。

## 操作

- 未锁定时，按住悬浮窗任意区域并拖动即可移动；锁定后不能拖动。
- 点击悬浮窗右上角 `×` 可打开菜单，切换窗口置顶或位置锁定，并访问设置、最小化和退出操作。
- 右键单击托盘图标可访问窗口置顶、位置锁定、显示/隐藏、设置、最小化和退出。
- 左键单击托盘图标可切换窗口显示状态。

## 运行

安装 Python 3 后，在项目目录运行：

```powershell
python main_tk.py
```

首次启动时填写设置并保存。以后可从悬浮窗菜单或托盘菜单重新打开设置。

## 打包

项目使用 PyInstaller spec 配置。安装 PyInstaller 后，在项目目录执行：

```powershell
pyinstaller 上班鼓励器.spec
```

最终可执行文件名称由 spec 中的 `name` 字段决定，当前配置为 `goToWork.exe`。
